# Furniture plan

Mobile-first, to-scale furniture planner for a one-bedroom apartment. Single file, no build step: open `index.html`.

- Drag pieces, pinch to zoom, drag the background to pan
- Add furniture from a catalog (twin to cal king beds, sofas, tables, storage, TVs, rugs) or a custom size
- Swap bed and TV sizes in place
- Live fit check: overlaps, pieces outside the walls, blocked doors, tightest gap
- Three starting layouts, plus named layouts saved on the device

Floor plan dimensions live in the `WALLS`, `FIX` and `DOORS` constants at the top of the script, in inches.
